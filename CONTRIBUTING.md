# Contributing

Thanks for considering a contribution to Developer Playground!

## What fits this project

Small, dependency-free Python utilities that solve real developer problems. Keep changes focused, tested, and easy to understand.

## How to contribute

1. Search existing issues and pull requests to avoid duplicate work.
2. Open an issue describing the problem and the proposed behavior, especially for larger changes.
3. Fork the repository or create a feature branch.
4. Make your change, with standard-library tests in `tests/`.
5. Run `python -m unittest discover -s tests -v` from the repository root.
6. Open a pull request with a summary, test results, and references to related issues.

Use clear commit messages and be considerate when reviewing others' contributions.

## Collaboration and attribution

Credit actual work. Add a Git `Co-authored-by: Name <verified-email@example.com>` trailer only when the named person genuinely contributed to that commit and agreed to the attribution. Do not use fabricated contributors or contributions to pursue profile achievements.

## Security

Do not put secrets, tokens, credentials, private project source, or personal data into issues or pull requests. If you discover a sensitive security problem, avoid posting exploit details publicly; contact the repository owner first.
